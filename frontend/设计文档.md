## 1. 项目概述

### 1.1 项目简介

Frontend 是一个股票模拟交易平台的前端应用，采用 React 18 + TypeScript + Vite 技术栈构建，为用户提供股票行情查看、模拟交易、持仓管理、交易历史查询等核心功能。

### 1.2 核心功能

| 功能模块 | 说明 |
|---------|------|
| 用户认证 | 登录、注册、Token 持久化 |
| 行情展示 | 股票列表、搜索、筛选、排序、分页 |
| 股票详情 | 股票信息展示 |
| 模拟交易 | 买入、卖出股票 |
| 持仓管理 | 查看当前持仓、盈亏分析 |
| 交易历史 | 查看历史成交记录 |
| 账户中心 | 账户余额、资产统计 |

### 1.3 后端对接

- **Base URL**: `http://localhost:8080`（可通过 `VITE_API_URL` 环境变量配置）
- **认证方式**: JWT Bearer Token
- **响应格式**: 统一 `{ code: number, message: string, data: T }`

## 4. 路由设计

### 4.1 路由配置 (App.tsx)

| 路径 | 组件 | 类型 | 说明 |
|------|------|------|------|
| `/login` | Login | Public | 登录页 |
| `/register` | Register | Public | 注册页 |
| `/` | Dashboard | Protected | 首页/仪表盘 |
| `/market` | Market | Protected | 股票行情 |
| `/stock/:code` | StockDetail | Protected | 股票详情/交易 |
| `/holdings` | Holdings | Protected | 我的持仓 |
| `/history` | History | Protected | 交易历史 |
| `/account` | Account | Protected | 账户中心 |
| `*` | → /login | Catch-all | 未匹配路由重定向 |

### 4.2 路由保护机制

**ProtectedRoute**:
- 检查 `isAuthenticated` 和 `isLoading` 状态
- 未认证重定向到 `/login`
- 认证后使用 `Layout` 组件包裹内容

**PublicRoute**:
- 已登录用户访问自动重定向到 `/`

### 4.3 路由参数

| 页面 | 动态参数 | 说明 |
|------|---------|------|
| StockDetail | `:code` | 股票代码 |

- Base URL: `http://localhost:8080`（可配置）
